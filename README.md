# คิดถึงจึงเขียนโค้ด (kidtuenggg)

เว็บแอปพลิเคชันขนาดเล็กสำหรับส่งต่อกำลังใจและพลังบวกให้แก่เพื่อน ๆ ในโรงเรียน พัฒนาขึ้นโดยฝ่ายเทคโนโลยี คณะกรรมการสภานักเรียน 

A mini web application designed to share encouragement and positive energy with students, developed by the Technology Department of the Student Council.

##  Features
- **Personalized Message:** กรอกรหัสนักเรียนเพื่อดึงข้อมูลรายชื่อจากฐานข้อมูล (Mock Data) มาแสดงผลเป็นข้อความทักทายเฉพาะบุคคล
- **Interactive UI:** มีปุ่มเลือกสถานะอารมณ์/ความรู้สึกในแต่ละวัน เพื่อเปลี่ยนข้อความฮีลใจให้ตรงกับความรู้สึกของผู้ใช้งาน

##  Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Deployment: Netlify
